### Topics listed under each domain

- **Splunk Basics:** Splunk components, uses of Splunk, apps, customizing user settings, basic navigation
- **Basic Searching:** run basic searches, set the time range, identify the contents of results, refine searches, use the timeline, work with events, control a search job, save results
- **Using Fields in Searches:** understand fields, use fields in searches, use the fields sidebar
- **Search Language Fundamentals:** review basic commands and practices, examine the search pipeline, specify indexes, use `table`, `rename`, `fields`, `dedup` and `sort`
- **Basic Transforming Commands:** `top`, `rare`, `stats`
- **Reports and Dashboards:** save a search as a report, edit reports, statistics and visualization reports, create a dashboard, add a report to it, edit it
- **Lookups:** describe lookups, examine a lookup file, create a file and a definition, configure an automatic lookup, use it in searches
- **Scheduled Reports and Alerts:** describe and configure scheduled reports, describe and create alerts, view fired alerts

## Suggested training (from the blueprint)

The blueprint lists these Core Certified User learning path courses as suggested and non-exhaustive: Intro to Splunk, Using Fields, Scheduling Reports and Alerts, Visualizations, Working with Time, Statistical Processing, Leveraging Lookups and Subsearches, Search Optimization. It also says candidates may use the Splunk How-To YouTube channel and Splunk Docs.
