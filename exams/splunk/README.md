# Splunk Certifications

Splunk is a platform for searching, monitoring and analyzing machine data: logs, metrics and events from applications, infrastructure and security tools. It is used for IT operations, security monitoring and business analytics, and it comes as Splunk Enterprise (run by you) and Splunk Cloud Platform (run by Splunk).

Splunk's certification page lists a ladder of core, administration, architecture and security certifications. Splunk certification registration and exam history now run through Cisco's systems, a change the Splunk page announces on its face.

## Where to start

Start with the entry-level Core Certified User. It has no prerequisites and teaches the search language every other Splunk exam builds on.
