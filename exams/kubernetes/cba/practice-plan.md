# CBA Study Plan

Four weeks at 4-6 hours per week. Customizing Backstage is 32%, but the catalog and configuration facts carry many detail questions.

## Week 1: Run it and deploy it

- [ ] Read note 01: prerequisites, create-app, layout, ports
- [ ] Read note 02: architecture, configuration, deployment checklist
- [ ] Optional lab: `npx @backstage/create-app@latest`, then `yarn start` (needs about 20 GB disk)

## Week 2: The catalog

- [ ] Descriptor format and the Component spec
- [ ] Annotations table
- [ ] Locations, `catalog.rules`, GitHub discovery
- [ ] Life of an entity and the troubleshooting checklist

## Week 3: Plugins and the app

- [ ] Frontend versus backend plugins and where each installs
- [ ] `createFrontendPlugin`, `PageBlueprint`, `app.packages: all`
- [ ] `createBackendPlugin`, modules and extension points
- [ ] Themes: `createUnifiedTheme`, BUI tokens

## Week 4: Review

- [ ] Take the [31 practice questions](../../../resources/practice-questions/cncf-cba.md) and re-read notes for misses
- [ ] Re-read the [scenarios](./scenarios.md)
