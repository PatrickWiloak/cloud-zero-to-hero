# Datadog Fundamentals Study Plan

Three weeks at 4 to 6 hours per week. The guide gives no weights, so the plan spreads time by how much each domain's content can be tested.

## Week 1: The machine and the Agent

- [ ] Read note 01 and read three YAML, JSON and shell examples aloud
- [ ] Read note 02: keys, sites, install, hostname precedence
- [ ] Read the Canonical Hostnames docs page named in the guide
- [ ] Optional lab: Datadog trial, install the Agent on a VM or container, find the host in the Infrastructure List

## Week 2: Networking and data collection

- [ ] Read note 03 and write the port table from memory
- [ ] Read note 04: the four routes, metric types, DogStatsD format, tags
- [ ] Send one metric with DogStatsD and find it in the Metrics Summary

## Week 3: Troubleshooting, visualization, review

- [ ] Read note 05 and run `status`, `configcheck`, `check` and read the log
- [ ] Read note 06 and build a dashboard with a template variable and a multi-alert monitor
- [ ] Re-read [scenarios](./scenarios.md) and [strategy](./strategy.md)
- [ ] Re-read every doc page the exam guide names under Documentation
