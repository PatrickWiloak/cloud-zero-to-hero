# Datadog Certifications

Datadog is a SaaS observability and security platform: infrastructure metrics, logs, application traces, dashboards and monitors. A small program, the Agent, runs on hosts and containers and sends data to Datadog; services you cannot install on are read through their APIs.

Datadog's certification overview page lists five exams, all multiple choice: Datadog Fundamentals, Log Management Fundamentals, APM and Distributed Tracing Fundamentals, Cloud SIEM for AWS Fundamentals and Database Monitoring Fundamentals.

## Where to start

Start with Datadog Fundamentals, the foundational exam. The other four are product-specific and assume the Agent, tag and monitor ideas it teaches.
